# Defensive playbook

25 original game calls based on standard football responsibilities: 4-3, 3-4, 4-4, 5-2, Nickel 4-2-5, Nickel 3-3-5, Dime 4-1-6 and Goal Line 6-2. Each front has Man, Zone and Blitz; Dime also has Prevent.

Open Coach’s Office > Defensive playbook to browse diagrams and save a preferred call. During practice use Defense, or Plays while on defense. Multiplayer uses Calls > defensive playbook. Filter by front and call type. Legacy four coverage values remain readable for existing matches.

Every call defines eleven positions and assignments, with personnel drawn without duplicates from the roster. If a roster lacks enough players of a package’s position group, another available defender fills in. The simulation executes rush paths, man targets and zone landmarks; these are simplified game implementations, not an NFL playbook or exact pattern-match coverage system.

Concept reference: USA Football, Defensive Trends: Coverages, Fronts and Pressures, https://blogs.usafootball.com/blog/7457/defensive-trends-coverages-fronts-and-pressures. Diagrams and game assignments were authored here; no proprietary playbook assets copied.

Validation: all 25 calls field eleven unique defenders with the expected DL/LB/DB counts on a complete roster and produce finite simulation frames. Multiplayer authenticates and validates the selected call against the server catalog.
